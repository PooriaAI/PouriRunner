# Pouri Runner — پروژه آماده ساخت APK اندروید

این پروژه بازی Pouri Runner را داخل یک اپ اندرویدی آفلاین قرار می‌دهد. بازی از فایل محلی اجرا می‌شود و برای اجرا به اینترنت نیاز ندارد. رکورد با localStorage در همان نصب/داده‌های برنامه نگه‌داری می‌شود.

## نکته مهم
این ZIP **سورس پروژه اندروید** است، نه فایل APK نصب‌شدنی. در محیط فعلی ابزار Android SDK/Gradle برای کامپایل مستقیم APK نصب نیست؛ برای ساخت APK از روش GitHub Actions زیر استفاده کن. برای این کار به حساب GitHub نیاز داری.

## ساخت APK با گوشی (بدون کامپیوتر)

1. دانلود ZIP پروژه و از حالت فشرده خارج کردن آن.
2. در GitHub یک مخزن جدید بساز (New repository).
3. فایل‌های داخل پوشه `PouriRunnerAndroid` را به مخزن اضافه کن. اگر آپلود پوشه در موبایل سخت بود، می‌توانی از GitHub در مرورگر دسکتاپ‌نما یا یک برنامه مدیریت Git استفاده کنی.
4. پس از اضافه شدن فایل‌ها، وارد زبانه **Actions** شو.
5. گردش‌کار **Build Android APK** را اجرا کن.
6. پس از اتمام موفق، در صفحه اجرای workflow به بخش **Artifacts** برو و `PouriRunner-debug-apk` را دانلود کن.
7. ZIP آرتیفکت را باز کن و فایل `app-debug.apk` را روی گوشی نصب کن. ممکن است Android از تو بخواهد اجازه نصب از همین منبع را فعال کنی.

## ساخت محلی با Android Studio
اگر Android Studio و Android SDK داری، پروژه را باز کن و `assembleDebug` را اجرا کن. APK خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.
